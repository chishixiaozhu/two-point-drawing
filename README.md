# 双点描形 · 免费非商业试用版

两个点分别沿横轴和纵轴滑动，间距恒定；连线上的描绘点画出圆、心形或五角星。仅保留二维描形阶段，12秒、横屏、静音。

## 交给 WorkBuddy

取得完整资料包后，让WorkBuddy读取其中的SKILL.md和VERSION，再说：

> 使用当前资料包的双点描形二维版。让两点在横纵轴上运动，画出一个圆，先预览，不导出视频。

继续说“换成心形”或“换成五角星”，它会另存新版本。圆的描绘点是中点；心形与五角星的描绘点在线段上改变位置，端点间距始终不变。

满意后说“导出视频”，打开导出页面点击导出并保持前台。优先MP4，环境不支持则回退WebM；WorkBuddy内置页面不能下载时，再用桌面浏览器打开同一文件。

需要已有Python 3和支持Canvas/MediaRecorder的浏览环境，不自动安装全局依赖。请使用本包版本two-point-nc-1，不调用其他目录中的旧kinetic-explainer。
